# 人工确认支付简化（2026-10-20）

用户授权合并人工确认弹窗，取消交易号输入，测试通过后上线。

订单列表和支付记录共用确认弹窗：显示订单/充值编号、渠道及应收，填写实际到账金额、确认币种并勾选人工核实后提交。错误在弹窗中显示，提交期间禁止重复操作。

后端允许省略 transaction_id，仍要求明确的 payer_verified、实际到账金额和真实结算币种一致，并保留付款风控、状态及订单/充值归属校验。TWQR 和 USDT 按保存的报价核对，不能把 CNY 账面金额当成实际转账金额。

无交易号时使用内部 admin-confirm:<payment id> 核销键，ProviderRef 不生成假平台交易号，记录 receipt_verification=admin_attestation。内部键仅用于同单幂等，不证明平台到账，也不提供跨订单同一流水去重能力；管理员负责实际核对。旧客户端仍可提交真实交易号，并保留原唯一约束；旧核销重试保留既有流水信息。

本次不新增付款或退款通道，不修改收款二维码及商城前台；不以真实订单作为测试数据。验证、发布指纹及备份另记录于限定发布证据。
