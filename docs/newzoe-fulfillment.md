# NewZoe 自动发货配置

1. 登录 [NewZoe 我的账户](https://shop.newzoe.cloud/account) 生成个人 API Key 和 API Secret。Secret 仅显示一次，请存入密码管理器。自动采购从该账户扣人民币余额。
2. 部署支持 NewZoe 的商城后台、API 和采购 worker 后，在商城后台「对接管理 → 连接管理 → 新建连接」选择 **NewZoe Shop API v1**，填入名称和个人凭据。站点地址自动填为 `https://shop.newzoe.cloud`。保存并测试连接，确认返回人民币余额。轮换凭据时编辑同一连接。
3. 新连接按人民币汇率 1、加价 60%、向上取整到元计算售价，默认同步上游价格。可在保存前调整。以进价 ¥6.03、¥5.00、¥8.34 计算，下表为对应商品的首发参考价。

   | 上游 ID | 商品 | 零售价 |
   | --- | --- | --- |
   | 24 | 多邻国 Super 12 个月激活码 | ¥10 |
   | 21 | Muse 1B 额度成品号 | ¥8 |
   | 22 | Muse 31B 额度成品号 | ¥14 |

4. 进入「商品映射 → 从上游导入」，选该连接和本地分类，勾选三个商品并批量导入。导入后商品默认下架。核对 SKU、库存、限购、价格和商品说明后再上架。
5. 买家付款后，采购 worker 用余额购买，按上游订单号轮询，完整取得交付内容后才写入买家订单。上游余额不足或采购异常时，查看「采购单管理」并按本地单号核账。上游已扣款的订单应继续查询原单，避免人工另购。

[上游 API 文档](https://shop.newzoe.cloud/docs/api/zh)
