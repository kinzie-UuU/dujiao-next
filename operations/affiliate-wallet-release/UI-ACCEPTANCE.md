# 推广奖励 UI 验收 · 2026-10-17

## 范围与依据

用户任务：在既有个人中心查看奖励、复制推广链接、转入本站消费余额、核对奖励记录。仅修改已部署的推广兼容面板及其交互测试，保留真实账户资料卡、侧栏、导航、钱包、付款流程和服务端规则。

先阅读 storefront 的现行 UI 规范及验收清单，并与当前生产容器的 HTML/assets 所渲染的钱包页比较。预览使用实际商城资源、本地模拟 API、preview@example.invalid 账户，不读取客户数据，不产生真实交易。先在完整账户上下文制作候选桌面/手机预览，再将候选脚本接入发布源码。

原问题：错误使用未定义的 --card/--border；一张大卡片混放规则/金额/表单；多个黄色按钮没有主次；记录为圆点列表；空状态栏占据固定空白；缺少真实账户外壳预览。

## 实现

- 使用账户页 --ui-bg-elevated/--ui-border/--ui-text-muted，回退到整站 --u-*；保留荧光黄绿主操作、现有字体、500/400 字重。
- 面板填满现有账户内容列，不新增外部容器。统计、转入操作、分享链接、奖励记录及折叠规则分层。
- 复制与刷新使用次要按钮；输入16px避免手机聚焦放大，按钮至少44px。
- 记录使用带表头/列作用域/日期 time 的表格，手机每条显示金额和状态、下一行时间。
- 未开通、零余额、空记录、错误和成功反馈均有真实对应状态。成功转入但读回失败时保留明确提示并锁定旧转入按钮，刷新成功才恢复。
- 人工确认收款后可用、退款扣回、本站使用/不提现及金额上限规则保持不变。
